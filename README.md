# BIOSAKA

## Descrição
O nosso projeto envolve desenvolver uma plataforma digital que traduza informações para os apicultores sobre suas colmeias, buscando ao máximo economizar pequenos gastos para impactar o fechamento das contas no positivo.  Em outro viés, nosso principal trabalho é desenvolver um SOFTWARE para pessoas que normalmente são leigas no uso de tecnologia em um geral, que, por meio de analises e predições, informará o usuário sobre o melhor período para colheita e intervensão do apicultor.
